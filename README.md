# Портфолио технического писателя (Technical Writer & Knowledge Engineer)

Добро пожаловать в мое портфолио технической документации. Здесь собраны образцы коммерческих и системных документов, разработанных с применением подхода **Docs-as-Code** (Markdown, YAML, OpenAPI).

## Содержание портфолио

1. **[Техническое задание по ГОСТ 34.602 («Invest-Links»)](./01_TZ_GOST34_Invest_Links.md)**
   * **Тип:** Проектная и системная документация (B2B / ФинТех).
   * **Суть:** Описание архитектуры, функциональных требований, ролевой модели и требований к информационной безопасности инвестиционной платформы.

2. **[Спецификация REST API / OpenAPI 3.0.3 («Кардио-Поток»)](./02_REST_API_OpenAPI_CardioFlow.md)**
   * **Тип:** Документация для разработчиков и интеграторов (API Reference).
   * **Суть:** Описание эндпоинтов, авторизации по Bearer-токену, схем запросов/ответов в формате YAML и кодов ошибок медицинского сервиса.

3. **[Руководство пользователя / User Guide («Сибирь-Экспресс»)](./03_User_Guide_Siberia_Express.md)**
   * **Тип:** Продуктовый UX-райтинг и справочный центр (B2C).
   * **Суть:** Пошаговые сценарии работы с мобильным приложением, оформление групповой корзины и раздел Troubleshooting на понятном языке.

4. **[Руководство системного администратора / Admin Guide («Сибирь-Экспресс»)](./04_Admin_Guide_Siberia_Express.md)**
   * **Тип:** Эксплуатационная документация (DevOps / Deployment).
   * **Суть:** Системные и сетевые требования, развертывание стека (FastAPI, PostgreSQL, Redis, Nginx) через Docker Compose, диагностика сбоев и настройка бэкапов.

5. **[База знаний для AI-ассистента / RAG & Prompt Engineering («Алтай-ФинТех»)](./05_AI_Knowledge_Base_Altai_FinTech.md)**
   * **Тип:** Инженерия знаний для нейросетей (AI-Ready Documentation).
   * **Суть:** Атомарные чанки с YAML-метаданными для векторного поиска, System Guardrails против галлюцинаций, матрица эскалации и Evaluation Dataset.

---

## Стек и компетенции
* **Стандарты и нотации:** ГОСТ 34, OpenAPI 3.0.3 (Swagger), Docs-as-Code, AI-Ready / RAG.
* **Форматы и инструменты:** Markdown, YAML, JSON, Obsidian, Git / GitHub, PlantUML / Mermaid.
* **Стилистика:** Инфостиль, строгий инженерный стиль, UX-райтинг.
